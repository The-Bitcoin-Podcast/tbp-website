## Episode Description

Today we talk with Luke Lombe from Cryptyk. Cryptyk is building Decentralized Cloud Storage with Blockchain Security with the goal of becoming the complete decentralized solution for Cyber-Security and Cloud Storage that protects against all major security threats to the cloud. Cryptyk replaces 3 - 4 existing cloud vendors by utilizing the Vault, a decentralized multi-cloud storage platform with sub-file level encryption and sharding that dramatically reduces the potential attack surface for hackers and viruses. And, the Sentry, a decentralized blockchain platform for auditing, tracking and monitoring all user access and file sharing by leveraging the permanent, immutable nature of the blockchain.
