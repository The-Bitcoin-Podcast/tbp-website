## Episode Description

Amazon Web Services (AWS) cloud platform has recently introduced its Blockchain framework for Ethereum and Hyperledger Fabric allowing users to build and manage their own Blockchain. According to the statement, users will be able to create their own Blockchain applications via the AWS CloudFormation Templates tool to avoid the time-consuming manual setup of their Blockchain network. We dive into this news headfirst. Then, Ubitquity LLC, the first blockchain-secured platform for real estate recordkeeping, is pleased to stop by the studio for a 4th time.
